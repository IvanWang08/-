# 超级玛丽 · 山河远行 v0.3

Three.js + Vite 制作的明亮国风 3D 横版动作过关游戏。v0.3 保留 420 单位四区域与防穿模物理，重做固定侧视相机与明亮光照，并加入金箍棒、冲刺、二段跳和数据驱动陷阱。

## 运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## 操作

- `A` / `D` 或左右方向键：行走
- `Space` / `W` / 上方向键：跳跃；按住跳得更高
- 空中再次按跳跃键：二段跳
- `J`：金箍棒挥砍；普通敌人一击，精英怪三击
- `Shift` / `K`：短距离冲刺，期间可穿过伤害机关
- `S` / 下方向键：进入水管
- `Esc`：暂停或继续
- `F`：显示 FPS 与 draw call
- `R`：重新开始

## 四个区域

1. **青竹林 0–100**：教学路线、竹林、亭子、弹簧、地刺与火焰节奏段。
2. **山间村 100–200**：民居、飞檐路线、水管、摆锤、刀轮与落石。
3. **水桥渡 200–300**：水面、木桥、移动/碎裂平台、飞刃与滚石。
4. **宫门前 300–420**：石阶、宫门、机关冲刺段、精英怪和终点牌坊。

每区都有高低路线、界碑检查点、隐藏砖与暗藏铜钱。坠落或受伤后会从最近界碑重生。

## 技术实现

- 相机保持 19.1° 轻俯角且 yaw / pitch / roll 不随输入变化，只平滑平移；角色位于画面左侧约 1/3、垂直近中线。
- WebGL 开启 MSAA，透视范围收紧到 `0.1–105`；共面装饰错层或启用 `polygonOffset`，阴影设置 bias/normalBias。
- 渐变天穹、青雾、暖色主光与冷色补光构成高调光照；朱红、鎏金、青灰、翠绿、天青共同配色。
- 石狮、飞檐金边、灯笼串、莲花座、战鼓、旌旗、经幢、祥云、石灯与远山均由基础几何程序化生成。
- 物理以 `1/120s` 固定时间步运行，渲染帧率不改变模拟结果。
- 玩家与敌人采用 X/Y 分轴碰撞；大位移按角色尺寸细分，实现 CCD 兜底。
- 地形 AABB 全部来自 `src/world/levelData.js`，渲染和碰撞共享同一份关卡数据。
- 移动平台会携带角色，遇到墙或天花板会停止，避免把角色挤进碰撞体。
- 场景按 25 单位区块显隐；竹林、草丛、建筑零件、敌人与铜钱大量使用 `InstancedMesh`。
- 水面为程序化扰动网格，远山、瓦片、木纹、石纹和落叶均在运行时生成，不依赖外部美术素材。
- 只有一盏平行光投射实时阴影，阴影范围随玩家移动。
- 8 类陷阱统一读取配置表：地刺、伸缩刺、火焰、摆锤、刀轮、落石、滚石、飞刃；全图编排为 7 个节奏组合段，并在首次实战前提供无伤预演。
