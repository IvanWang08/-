# 超级玛丽 3D · v0.1

使用 Three.js 和 Vite 制作的单关卡 3D 横版过关小游戏。所有角色与场景均由基础几何体组成，不依赖外部模型、贴图或物理引擎。

## 已实现

- 蓝天、远山、云朵、连续地面与悬浮平台构成的单关卡
- 横向移动、重力、带按键时长的可变高度跳跃和镜头跟随
- 12 枚可收集金币与实时分数/金币/生命 HUD
- 6 个巡逻板栗仔，支持踩杀、侧碰受伤和击退反馈
- 坠落扣命、出生点重生、Game Over、终点旗与通关结算
- `R` 键和结束画面按钮均可完整重开一局

## 本地运行

```bash
npm install
npm run dev
```

打开终端给出的本地地址即可开始游戏。生产构建：

```bash
npm run build
npm run preview
```

推荐 Node.js `20.19+`。依赖版本已在 `package.json` 中精确锁定。

## 操作

- `A` / `D` 或左右方向键：移动
- `Space` / `W` / 上方向键：跳跃；按住可跳得更高
- `R`：随时重新开始

## 目标

收集金币、踩掉或避开板栗仔，抵达关卡最右侧的旗杆。侧面碰到敌人或掉出地图会损失一条生命，生命归零则游戏结束。

## 技术栈

- Three.js `0.186.1`
- Vite `8.3.1`
- 原生 JavaScript ES Modules

## 目录结构

```text
src/
├── enemies/   # 板栗仔外观、巡逻和碰撞
├── player/    # 玩家模型、输入与跳跃物理
├── scene/     # Three.js 场景、相机、灯光和渲染器
├── ui/        # HUD、Game Over 与通关画面
├── world/     # 地形、金币和终点旗
└── main.js    # 游戏状态与渲染循环
```

## 规则说明

- 每枚金币 `+100` 分，踩掉板栗仔 `+250` 分。
- 抵达旗杆获得 `+1000` 分，并按剩余生命每条追加 `+200` 分。
- 玩家共有 3 条生命；侧面碰到敌人或掉出关卡会损失 1 条。
