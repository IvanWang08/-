# 超级玛丽 · 山河远行 v0.4

Three.js + Vite 制作的明亮国风 3D 横版动作过关游戏。v0.4 将关卡扩展到 800 单位和六大区域，导入原创骨骼动画侠客，重做金箍棒扫掠判定、装饰落地、移动平台插值、性能监测与节奏陷阱。

## 运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## 操作

- `A` / `D` 或左右方向键：行走
- `Space` / `W` / 上方向键：跳跃；空中再按一次二段跳
- `J`：挥舞金箍棒；普通敌人一击，精英怪三击
- `Shift` / `K`：短距离无敌冲刺
- `S` / 下方向键：进入水管
- `Esc`：暂停或继续
- `F`：显示 FPS、draw call、三角形与 JS 内存
- `R`：重新开始

## 六个区域

1. **青竹林 0–100**：跳—冲—跳教学段、竹林、亭子与弹簧。
2. **山间村 100–200**：民居飞檐、水管与三摆锤错相位阵。
3. **水桥渡 200–300**：木桥、移动/碎裂平台与火焰交错段。
4. **宫门前 300–400**：石阶、宫门与飞刃—落石跑酷长廊。
5. **石窟栈道 400–600**：佛像浮雕、单木栈道、开合佛掌与连续机关。
6. **云海天宫 600–800**：浮岛云阶、追逐滚石、精英守卫与金边南天门。

每区都有高低路线、界碑检查点、隐藏砖与暗藏铜钱。坠落或受伤会从最近界碑重生。八类机关在首次实战前均有无伤演示，正式机关全部归入 3–6 拍组合段，难度由 A 区逐步提高到 F 区毕业段。

## v0.4 技术要点

- 物理以 `1/120s` 固定步长运行；玩家、敌人、移动平台和攻击判定都与渲染帧率解耦。
- 金箍棒前 2/3 挥砍过程执行 160°、半径 3 单位的连续胶囊扫掠；同一敌人每次攻击只命中一次，并用场景 AABB 做隔墙遮挡。
- 装饰物由统一地形碰撞表计算落点；远背景、中景、近景、玩法、前景五个 Z 区间集中定义在 `src/world/layers.js`。
- 移动平台保存前后两个物理位置，渲染时插值；顶面错层超过 0.005，关闭动态平台投影以避免阴影频闪。
- 32 个 25 单位区块按视野缓冲显隐；装饰按几何/材质合为 `InstancedMesh`，远近 LOD 使用重叠迟滞区防止跳变。
- 单盏 PCF 滤波实时阴影跟随视野，远区装饰不投影；粒子和挥砍残影使用固定容量对象池，热路径不创建颜色对象。
- F 面板同时显示 FPS、draw call、三角形和内存，便于 1080p 实机验收。
- 相机固定 19.1° 轻俯角，只平滑平移；WebGL 开启 MSAA，透视范围收紧到 `0.1–105`。
